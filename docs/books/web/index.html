HTTPD (httpd) for MVS 3.8j

An HTTP/1.1 server for MVS 3.8j. It serves static files from a UFS file system of UFSD and runs server modules, such as mvsMF, that provide REST APIs for MVS. Two books describe HTTPD 4.5.
