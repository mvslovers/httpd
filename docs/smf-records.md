# HTTPD SMF Records

The SMF records of HTTPD (httpd) are described in the _HTTPD Reference_
(ML07-0002), chapter "SMF Records": the record types and subtypes, the header,
the request record and the session record field by field, the levels and the
Parmlib keywords that switch them, and how to read the records.

The manuals are attached to each release from 4.5.0 on as
`ml07-0001-<edition>.pdf` and `ml07-0002-<edition>.pdf`, and their sources are
in [`docs/books`](books).
